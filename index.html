10. Image Count + Variation Engine

Choose 1–10 images. If you select a Vary option, the generated prompt will now explicitly enforce different choices for that category across Image 1, Image 2, Image 3, etc. A coordinated collection should match as a set, but the images should not repeat the same design.

Disclaimer: This design may not be edited, resold, or modified.
Coordinated Collection = same overall concept, mood, and visual identity, but different designs. If you check Vary Hairstyle, Vary Clothing, Vary Background, Vary Accessories, Vary Aesthetic, Vary Color Scheme, Vary Decorative Elements, Vary Message, or Vary Pose, those categories should visibly change from image to image.
